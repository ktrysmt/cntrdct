# cntrdct

Evidence-based contradiction linter for Rust. Every detector must cite
peer-reviewed prior art before it can register; the framework rejects
citation-free detectors at startup. Five Layer 1 detectors ship today,
backed by a statistical ranker, an optional LLM adjudicator, and a
SARIF emitter.

[Source on GitHub](https://github.com/ktrysmt/cntrdct){:.btn}
